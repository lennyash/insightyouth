# 我用 Typecho 给自己搭了一个内容站

最近把自己的公众号内容沉淀成了独立站点：**有悟青年 InsightYouth**（https://www.insightyouth.cn）

主要写三类东西：

- **投资研究**：科技股、资源品、AI 产业分析，比如《未来10年普通人需要配置科技股的理由》《铜，是怎么逆袭为战略资源的？》
- **AI 技术实践**：大模型应用、排版自动化、小程序开发的一些实战记录
- **运营手记**：内容创作和公众号运营的思考

技术上用了 Typecho，主题是自己改的，服务器放在香港虚拟主机。从公众号到独立站的迁移过程踩了不少坑（图片本地化、CDN、SEO 配置），后面会陆续写成文章分享。

欢迎来逛逛，也欢迎交换友链：https://www.insightyouth.cn
